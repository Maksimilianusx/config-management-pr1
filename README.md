# Эмулятор оболочки ОС

Практическая работа по дисциплине «Конфигурационное управление».

Вариант №28.

## Общее описание

Проект представляет собой графический эмулятор командной оболочки UNIX-подобной операционной системы.

Программа реализована на Python с использованием библиотеки Tkinter.

Эмулятор поддерживает работу с виртуальной файловой системой VFS, которая загружается из ZIP-архива и хранится в памяти во время работы программы.

## Структура проекта

- `src/main.py` — основной код программы.
- `tests/test_parser.py` — тесты парсера команд.
- `scripts/` — стартовые и тестовые скрипты.
- `vfs/` — тестовые виртуальные файловые системы.
- `logs/` — XML-журналы выполнения команд.
- `run.bat` — быстрый запуск программы.
- `.gitignore` — список файлов, которые не добавляются в Git.
- `README.md` — документация проекта.

## Этап 1. REPL

На первом этапе реализован минимальный графический интерфейс эмулятора.

Реализовано:

- графический интерфейс GUI на Tkinter;
- заголовок окна на основе имени пользователя и имени компьютера;
- ввод команд пользователем;
- разбор команд;
- раскрытие переменных окружения, например `$HOME`;
- команды-заглушки `ls` и `cd`;
- команда `exit`;
- обработка неизвестных команд.

Пример:

```text
ls $HOME

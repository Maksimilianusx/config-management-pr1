# Эмулятор оболочки ОС

Практическая работа по дисциплине «Конфигурационное управление».

Вариант №28.

## Этап 1. REPL

На первом этапе реализован минимальный прототип эмулятора командной оболочки ОС с графическим интерфейсом.

### Реализованная функциональность

- графический интерфейс на Tkinter;
- заголовок окна формируется на основе имени пользователя и имени компьютера;
- реализовано раскрытие переменных окружения;
- команда-заглушка `ls`;
- команда-заглушка `cd`;
- команда `exit`;
- обработка неизвестных команд.

## Примеры использования

Команда:

ls

Результат:

ls: []

Команда:

cd test

Результат:

cd: ['test']

Команда:

ls $HOME

Пример результата:

ls: ['C:\\Users\\makson']

Неизвестная команда:

abc

Результат:

Ошибка: неизвестная команда 'abc'

Команда:

exit

Закрывает приложение.

## Запуск

Запуск напрямую через Python:

python src\main.py

Или через файл:

run.bat
